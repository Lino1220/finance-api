Finance API

Este projeto foi desenvolvido para fins de estudo e prática de desenvolvimento
de APIs REST utilizando Node.js, Express, PostgreSQL, bcrypt e JWT.

ESTADO DO PROJETO
-----------------

O desenvolvimento foi encerrado no Nível 2.

Funcionalidades implementadas:

- API REST com Express
- Integração com PostgreSQL
- CRUD de transações
- Cadastro de usuários
- Hash de senhas com bcrypt
- Login
- Autenticação com JWT
- Middleware de autenticação
- Rotas protegidas
- Associação de transações ao usuário autenticado
- Isolamento das transações entre usuários
- Testes básicos de autenticação e autorização

LIMITAÇÕES
----------

Este projeto não deve ser considerado uma aplicação financeira pronta para
produção.

Não foram implementados:

- Sistema de categorias normalizadas
- Relatórios financeiros
- Recuperação de senha
- Verificação de email
- Refresh tokens
- Controle avançado de permissões
- Rate limiting
- Logs profissionais
- Testes automatizados completos
- Validação avançada de dados
- Deploy em produção
- Outras medidas necessárias para um ambiente de produção

FINALIDADE
----------

O objetivo principal deste projeto foi permitir a prática dos conceitos
fundamentais de desenvolvimento de uma API REST, banco de dados, CRUD,
autenticação e autorização utilizando JWT.

O projeto está mantido como referência de estudo e poderá ser reutilizado ou
expandido futuramente caso exista uma necessidade real.
